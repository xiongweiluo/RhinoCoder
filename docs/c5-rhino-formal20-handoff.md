## 保管职责与一次性边界

仓库所有者本人是唯一 `reviewer_1` 和新 20 题的独立保管人；不需要另一名 `reviewer_2`。独立性指其保管的正式题和答案不用于训练、开发题、提示词、执行器、评分阈值或失败后的修补。开发代理只接收**无正文**的公开承诺和排除结论，不接收私有明文路径、密钥、答案、原 80 家族正文或单题提示。原 C5 80 家族及 A5/P2/R 已消费题均不可再当作未见正式题。

保管人先在代理不可访问的目录中准备 20 个不可拆分任务家族及答案，并私下完成全部排除，再加密封存。公开交接仅包含：新研究 ID、承诺版本、20/40 固定分母、五层计数、逐层覆盖摘要、加密 artifact 的 SHA-256/字节数/格式、20 家族及模板族承诺根、与冻结数据/历史排除/原 80 承诺的绑定哈希、零重合和近重复检查结果、保管人签署时间与未泄露声明。公开文件不得含正文、答案、密钥或明文位置。加密文件和保管人密钥不进入仓库、PR、训练主机开发目录或聊天。

开发侧只能校验公开字段和固定哈希，不定位或打开加密文件。正式运行的唯一新 `claim` 必须在所有者对**完整正式 spec 与 runtime freeze 的新精确哈希**明确批准后，以独占且持久的 `started` 事件先于任何解密或模型生成落盘。一次消费后无论质量结果、基础设施故障或安全停止，均不得换 ID/题目、从头重跑、补位或把失败槽剔除；只有事前写定、能证明没有越过相应消费/写入边界的同 run 只读恢复可考虑。原离线 80 家族的消费台账不重用，也不被本阶段修改。
