## 检查、停止和导出

完整模型与兼容环境检查集中在真实资格子进程加载入口；父监督器先完成完整配置/许可/身份校验而不重复扫描多 GB 模型。加载后完整性检查仍保留，避免加载期间资产变化。重复的同一次快照哈希扫描已移除。

`tools/c5_formal_reuse_control.py` 是独立停止/导出入口，静态计算并冻结其 Python 依赖闭包。它只需原完整 grant、固定公共材料、控制代码、资格身份和共享停止记录；不导入模型入口、模型加载器、Torch 或 runner，不执行模型资产/完整环境预检，不受生成预算或租期过期所阻。它不削弱 pidfd、UID/boot/start ticks/argv/executable/cwd 资格和一次信号约束。
