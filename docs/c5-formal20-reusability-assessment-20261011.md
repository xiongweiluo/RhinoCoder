## 二、必须区分的三个问题

1. **运行资格：**“已消费”是原协议的防重放状态，证明一次性屏障已跨越；它不是污染检测器，但在原协议内仍有约束力。
2. **开发隔离：**题目、答案、输出或评分是否进入训练、提示词/schema/parser、工具控制器、选模、阈值或任务选择过程。没有生成，也可能因题目泄漏失去隔离；有生成，也不必然表示输出被用于开发。
3. **对外表述：**同一题目再次评测不是新抽取的数据集，也不是独立新样本的复现实验。即使隔离得到充分支持，也须披露原中断、同题复用、协议改变和尝试次数，不能称原预注册首次运行成功。

保管人为出题、排除、封存或私下审阅而看题，不自动等于开发污染；关键是职责隔离及是否把信息传入开发决策。仓库所有者仍是唯一 `reviewer_1` 和独立保管人，不需要增加 reviewer_2；代理不能代签，也不能通过读取私有正文替代本人审阅。

## 五、补证后的判断规则

- **证明指定链路零生成/零派发，且内容和结果没有进入开发：**可以论证同一封存集仍未用于开发，再考虑公开修订协议下的复用；仍不是原 run 的恢复许可，也不是新题或原首次尝试成功。只有证据确实覆盖模型接触范围，才可窄称“模型首次正式接触”，不靠零计数命名。
- **有过生成/执行，但内容与结果始终保管隔离，未用于开发或结果选择：**不自动认定开发污染，但已经不是模型首次接触。可以评估隔离仍成立的同题重复研究；必须披露重复及其局限，不能声称新样本独立复现。
- **题目/答案/输出用于训练、任务针对性开发、选模、提示词或阈值选择：**不能再认证为相对该开发过程独立的最终盲测；可讨论显式诊断/回归用途。未执行的其他题不自动成为可挑出的“干净子集”。
- **证据仍不足：**维持本报告的“盲测复用资格未证实”，不永久宣判污染，也不认证盲性。如果只需要诊断价值，可另选透明重复评测路线；如果需要强的全新独立最终盲测主张，再考虑新的封存集。现在不生成新题。

“零生成”是支持隔离的一条证据，不是科学可复用性的唯一必要条件；“没有看过分数”也不是充分条件，因为题目本身或原始输出可能影响开发。
