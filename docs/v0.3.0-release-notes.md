# RhinoCoder v0.3.0 — Recruiter-readable, verifiable Rhino agent

RhinoCoder `v0.3.0` packages the project as a reproducible AI full-stack portfolio release: a Rhino 8 agent that executes geometry through versioned MCP tools, reads the scene back, checks programmatic assertions, and links privacy, routing, tool calls, recovery, cost, and evidence under one `run_id`.

## Highlights

- 500/500 admitted golden traces across 46 tags; A7 added 200 tasks and met all 8 planned coverage gaps.
- 270/270 fixed real-Rhino baseline runs passed across three configurations. This saturated 30-task contract is not presented as open-world performance.
- Rule-first hybrid routing with a mandatory privacy gate, traceable decisions, bounded fallback, idempotent mutations, and recovery without replaying completed Rhino writes.
- Bilingual recruiter-first README, browser-readable architecture/data-flow SVGs, real-Rhino and no-Rhino Replay Quickstarts, and an evidence index mapping every public metric to a versioned report.
- A privacy-reviewed synthetic self-correction Replay and 960×540 GIF demonstrate an assertion mismatch, correction, re-check, and completion without exposing real user data.

## Verify locally

```bash
./scripts/release-verify.sh
```

Reviewers without Rhino can use `./scripts/start-replay.sh`. The full real-Rhino path requires Rhino 8 and a configured DeepSeek-compatible model endpoint.

## Honest boundaries

- `local-mock` validates the unified backend contract, privacy-forced routing, no-cloud-fallback behavior, and safe failure. It is not a real local inference backend.
- The A5 holdout and future P2 hard set remain frozen and are not used for training or repeated tuning.
- Formal GPU/LoRA experiments have not started because school GPU access is not yet available.
- The real Rhino demo video is deferred by the project owner. The included GIF is generated only from sanitized synthetic Replay data and is not presented as real Rhino footage.
