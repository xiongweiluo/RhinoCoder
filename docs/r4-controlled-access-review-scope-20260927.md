本分支仅提交隔离候选链路的代码、合成测试与本脱敏说明。原始现场审计、逐题任务文本、实例连接信息、私有模型权重和一次性密钥均不随分支发布。现场证据保留在操作者本机，供授权的人类评审单独核验；本文件不能替代原始收据。

## 本分支能与不能证明什么

候选入口的职责是只在独立、一次性、未保存的 Rhino headless 测试文档中工作；在每次远端发送和写入前执行身份、范围、隐私、参数、目标、场景、许可及防重检查，并在失败或不确定时停机、保留账本与回执。公开测试验证其中可脱离现场运行的状态机和负控；它们不是新的真实模型/Rhino 验收。现场第五题曾通过一次两步隔离烟测，审计文件未随本分支发布，不应仅凭本说明将该结果视为独立复核完成。

本分支缺少经人类评审的真实用户 opt-in 界面、预览与实际发送绑定、证据血缘和异常清理闭环。非作者代理审查指出这些阻断项；代理意见不等于真人批准。候选代码仅供审查及后续迭代，不应在生产用户文档、默认路由或多用户环境启用。

## 复现与证据边界

在干净检出中运行下列不依赖私有现场档案的测试：

```sh
pytest -q eval/test_r4_controlled_access_batch_v2.py eval/test_r4_controlled_access_candidate_v2.py eval/test_r4_controlled_access_default_isolation.py eval/test_r4_controlled_access_remote_guard_v2.py eval/test_r4_controlled_access_sqlite_backup.py
```

`batch_v2` 的合成单元测试明确替换私有 v8 基线读取；真实运行器没有替换，必须先验证原报告哈希、60 条原始结果和历史失败状态，档案缺失时应拒绝运行。真实模型、远端实例、Rhino 与未保存测试夹具均不在本分支的 CI 覆盖范围内。原始审计目录不加入 Git；若需独立现场复核，应另走受控的只读证据交接，不将敏感材料附在公开 PR。

为避免发布租用实例地址和本机临时连接目录，评审分支把旧源码中的端点改为显式运行时配置（`R4_APPROVED_HOST`、`R4_APPROVED_PORT`、`R4_APPROVED_USER`、`R4_KNOWN_HOSTS`、`R4_CONTROL_SOCKET`；SSH 主连接脚本另需 `R4_SOCKET_DIR`）。未配置时真实运行入口拒绝启动。这个可公开审查的代码快照与先前现场封存的源码哈希不同，不能冒充当时的现场执行源码；任何新现场验证须按新快照重新登记。

任何隐私越界、许可缺失、场景漂移、重放、写入结果不确定或清理无法核对，都必须停止候选路径并保持默认路线不变；不得通过降低安全门槛或删改失败记录求得通过。
