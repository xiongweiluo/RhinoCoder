# 第三阶段：300 条黄金轨迹任务设计

## 目标与依据

`phase3-300` 只读复用第一、第二阶段已确认的 100 条黄金轨迹，并新增 200 条长尾任务。设计依据是第二阶段 98 次运行的失败分布：颜色选择器未命中、贴合/中心位置误差和布尔差集恢复是主要薄弱点。因此第三阶段统一使用明确 RGB、尺寸、轴向、坐标和最终关系，避免“旁边”“大约”等不可验证表述，同时保留真实的多步恢复难度。

## 二十个审核批次

| 批次 | 任务 | 重点 |
|---:|---|---|
| 11–13 | p3-001–p3-030 | 贯穿孔、空心圆柱、穿出式球形切口 |
| 14–15 | p3-031–p3-050 | 非居中支承与三层居中堆叠 |
| 16–18 | p3-051–p3-080 | 群组、图层、群组对齐与净间距分布 |
| 19–20 | p3-081–p3-100 | Undo 与无效 GUID 错误恢复 |
| 21–22 | p3-101–p3-120 | 最高/最矮对象感知、精准删除与修订 |
| 23–24 | p3-121–p3-140 | 局部旋转、移动与非均匀缩放 |
| 25–26 | p3-141–p3-160 | 外切链、同心球柱群组 |
| 27–28 | p3-161–p3-180 | 圆曲线拉伸、六向精确贴合 |
| 29–30 | p3-181–p3-200 | 五件装配体与最终状态纠错 |

每批固定 10 条。前三类布尔任务要求干净工具轨迹；错误恢复类允许保留预期失败调用，但最终状态、程序断言、场景自检和人工视口复核必须全部通过。

## 质量约束

- 200 个连续唯一 ID 与 200 条唯一自然语言指令。
- 全部新增任务难度为 L4 或 L5；完整 300 条中 L4+ 不少于 260 条。
- 完整 campaign 覆盖不少于 40 个标签，且数字模板重复不超过 2 条。
- 每条任务至少有一个计数、属性或空间关系断言；复杂任务同时使用多类断言。
- 任务文件由 `tools/generate_phase3_tasks.py` 确定性生成，并由 `--check` 防止手工漂移。
- 真实采集继续执行程序断言、`get_scene_summary`、Rhino 截图、AI 初审、每 10 条人工 `APPROVE`、脱敏和原子晋级。

## 离线校验

```bash
python tools/generate_phase3_tasks.py --check
python tools/check_collection_campaign.py --manifest eval/collection/phase3_300.json
python agent/data_collector.py --manifest eval/collection/phase3_300.json --dry-run
./scripts/check.sh
```
