## 验证范围

本次只修改招聘者可读发布层、公开合成 Replay 与发布检查，不重做已经验收的 A/B 阶段，不执行 C1–C4，也不读取 A5 holdout 或未来 P2 困难集。项目所有者随后明确授权 P0 收尾，允许创建发布 commit、`v0.3.0` Tag、push 与 GitHub Release。

完整检查首次运行发现 `check.sh` 会在检测到本地黄金文件时自动重建 A5 数据。A7 已把源黄金集从 300 扩到 500，这会错误地把新增任务带入冻结实验，并与 A5 campaign 契约冲突。发布脚本已改为：只要冻结的 `data/training/a5/manifest.json` 存在，就执行 B1–B4 的哈希/行数/holdout 门禁审计；常规检查不再重建训练数据。该约束已加入发布一致性检查，防止回归。
