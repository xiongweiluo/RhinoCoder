## 官方计价与成本重算

本次使用 `deepseek-v4-pro`。DeepSeek 官方在 2026-08-27 公布的常规价格为：

- 缓存命中输入：$0.003625 / 1M token。
- 缓存未命中输入：$0.435 / 1M token。
- 输出：$0.87 / 1M token。

历史运行只保存了总输入 token，没有保存 API 响应中的缓存命中/未命中拆分，因此无法反推出唯一的实际费用。本报告按官方价格给出严格区间：下限假设所有输入均命中缓存，上限假设所有输入均未命中缓存。

| 模式 | 输入 token | 输出 token | 输入成本区间 | 输出成本 | 总成本区间 |
|---|---:|---:|---:|---:|---:|
| Baseline | 4,451,414 | 141,162 | $0.016136–$1.936365 | $0.122811 | $0.138947–$2.059176 |
| Closed-loop | 5,936,925 | 163,472 | $0.021521–$2.582562 | $0.142221 | $0.163742–$2.724783 |
| 合计 | 10,388,339 | 304,634 | $0.037658–$4.518927 | $0.265032 | $0.302689–$4.783959 |

保守按全部缓存未命中计算，Closed-loop 比 Baseline 增加 `$0.665607`（约 32.3%）；实际增量取决于缓存命中率。DeepSeek 官方已预告未来可能采用高峰时段 2 倍价格，但生效日期以官方公告为准，本报告未应用尚未生效的峰值倍数。

代码现已记录 `prompt_cache_hit_tokens` 和 `prompt_cache_miss_tokens`。后续运行会生成精确成本；对不返回缓存拆分的兼容 API，则继续明确输出上下界。
