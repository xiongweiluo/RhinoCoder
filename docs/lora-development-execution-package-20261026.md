## 执行、恢复和选择

实际入口按“新Mac控制器→一次Rhino wrapper→宿主ready→新GPU监督器/子进程→固定32槽→两端停止/导出”接续。宿主先核验签名/序号，controller独立重解析GPU原始输出，再对当前真实读回签发短时只读交接；真正的ResearchGate/SQLite完成额度及重复拒绝，读取回执、前后场景和实际账本逐项核对。仅字段一致或scorer自报success不能代替这条链。

普通解析、选工具、参数、策略或任务失败保留并继续预定槽；工程错误独立统计，其原生效果/根因可以仍未知。未知效果、错绑定、账本/证据异常、关闭未知、源码/资源变化、超时或用户停止均停止本批。未尝试槽保留，不删出分母。每一槽/步先永久登记，重开进程也不能重试已登记请求。

只有**第一次任务曝光前的加载故障**，且该新子进程退出/GPU缺席已核实，才自动使用唯一一次预批准恢复；当时尚无夹具请求。两次加载共用首次计时。任务开始后不重试、不换题、不改提示、不因成绩追加运行。CPU局部分析/修复可继续；更改执行字节或追加真实尝试，须集中更新受影响包并批准，不能沿本包无限修复重跑。

S全部结束后一次封存选择：候选合计净增成功、各权重分别不退化，且无新增工程/安全失败才选read_progress_v1，否则original。随后A只验收，不继续调参；A不维持同方向或新增工程失败则不声称收益，保留original或证据不足。全部S/A都登记为开发，不是独立最终盲测，后续最终集排除这些及其衍生家族。

异常也须接续到安全收尾：只关闭本轮确实拥有的文档；移除保留的精确回调；停止本轮子进程；核实GPU缺席；导出已停止的新证据；记录未尝试、未核实状态和资源结算。无法核实停止/关闭时保留unknown，不因输出报告就宣布安全收尾完成，也不重启同包。Rhino Idle是逻辑截止检查，不能抢占正在阻塞的CLR调用；不以该限制为理由杀掉用户Rhino或访问现有工程。

- 145项不同的相关CPU测试已覆盖V1/V2、登记、原始输出重解析、跨槽/签名/反馈拒绝、真实SQLite只读账本、合成32槽完整路径、部分开文档/模型断线/未知执行/关闭失败、入口返回门、管道超时、唯一恢复、导出校验及精确批准/时钟边界。后续代码修正只重跑受影响范围，完整CI见PR精确head。后续登记写入失败时仍保留已完成结果前缀；最终报告分别列登记槽数、完成结果数，并要求与永久账本核对，不能把未返回结果误记为未尝试。
- 现有3090环境只读核查24,298个解释器/依赖文件；没有导入模型库。Linux上新建3个无模型CPU子进程，核实自然退出、TERM、必要时KILL三条精确停止路径；没有搜索或停止旧进程。新构造失败清理另有CPU回归。
- Mac与Linux实际契约的28种输入/364模板字节、token数完全一致，最小余量130。旧长度审计中JSON工具字典排序导致的调用prompt哈希差异保留并单独解释；原长度结论成立，未为匹配审计修改正式提示词。此前临时探针的依赖遗漏、连接超时等准备失败保留，不记为模型或历史七项失败。
- **未证明：** 真模型时延/任务成功、真实Rhino几何及退出、候选反馈收益、历史七项根因、所有私有训练家族隔离、整个Rhino/CLR/外部动态库的完整字节闭包。源码/所用Python依赖核验是有限运行保证；原C4/C5 NO-GO、宿主审核限制和默认混合路线仍保留。本包不会替原研究补PASS。

8个公开开发任务内部S/A模板已隔离；与全部历史私有训练家族是否重叠仍未知。**允许本包作为已披露的公开开发，不能据它宣称独立于历史训练的泛化证据。** 这一未知不阻塞当前CPU工作，也不要求本人回填七项历史问题；第一阶段正式交付前，若独立性或覆盖仍不足，应明确受限结论和必要的最小补充，不能自动把只读8例扩大为12工具/写入/恢复全覆盖。

## 批准后的主任务接续

批准仅覆盖上面的首次真实开发执行及其收尾/审核，**不包括训练、旧实验重跑、最终集制作/消费、产品验证或PR合并**。收到明确完整包批准后，在范围内连续执行，不逐命令或逐用例询问。

开发完成后继续同一第一阶段：结合真实输出、工程失败和已有覆盖证据，封存系统选择并作训练/不训练判断；有训练依据才提交一次条件训练材料。随后固定参评模型、共同链、最终研究范围/N/分层、配对统计方法与效果判据、实际时延预算/停止规则和独立保管方式，交付完整最终比较准备包。当前40家族及2/4/16 GPUh仍是主计划中的建议，不能因为批准本次2小时开发就执行后续预算或提前制作最终集。
